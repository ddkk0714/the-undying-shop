## 1. 레이아웃 상수 (`src/ui/layout.ts`)

> **v3.1 — 기준 해상도가 1920×1080 으로 바뀌었다.** 아래 값이 정본이다.
> 구 480×270 값은 전부 ×4 한 뒤, 상점 화면만 레퍼런스에 맞게 새로 잡았다.

```ts
export const L = {
  W: 1920, H: 1080,

  // ── 공통 HUD (상단 144) — 액자 박스 2개 + 도구 띠

  hudStatus: { x:   8, y:  16, w:  752, h: 112 },  // DAY · LIVE · 골드/팬/평판

  stage:  { x: 0, y: 144, w: 1920, h: 936 },       // 단계별 본문 영역

  // ── ①② 상점 화면 — 2분할 + 하단 4택 (레퍼런스 정본)
  guest:    { x:   0, y: 144, w:  752, h: 792 },   // 좌: 방문자 / 출연자 전신

  live: {
    bar:      { x:    0, y:   0, w: 1920, h:   64 },  // LIVE · 방송 제목 · 시청자 수
    floors:   { x:    0, y:  64, w:  104, h: 1016 },  // 층수 게이지 (아래로 깊어짐)
    map:      { x:  104, y:  64, w:  496, h:  536 },  // 던전 지도 + 현재 위치

    choices:  { x:  600, y: 784, w:  744, h:  296 },  // 공격 / 방어 / 어필

    chat:     { x: 1344, y: 464, w:  576, h:  616 },  // 채팅

    paper:  { x: 768, y: 144, w: 1152, h: 792 },     // 계약서 전면
```

오른쪽 여백 192 는 도장·두루마리 자리다 (레퍼런스와 동일).

**하단 4버튼**: `pad 24`, 버튼 사이 12 → 폭 267 × 4 = 792, x = 792 / 1071 / 1350 / 1629.

### 2-1. Button 계약

```ts
new Button(scene, {
  x, y, w, h,
  label: '오른쪽이야',
  variant: 'default' | 'danger' | 'ghost',   // danger = wax 테두리
  onClick: () => store.dispatch({ type: 'RADIO/ANSWER', dir: 'B' }),
  hotkey?: '1' | '2' | '3',                  // 숫자키 지원 (심사자 편의)
});
```

**모든 주요 선택지에 숫자 핫키를 붙인다.** 데모 영상 촬영과 심사자 조작이 빨라진다.

### 2-2. Panel 스타일 2종

| variant | 채움 | 테두리 | 용도 |
|---|---|---|---|
| `raised` | `mid` | `bone` 2px | 카드, 버튼, 액자 |
| `sunken` | `ink` | `dust` 2px | 목록, 채팅창, 진열 슬롯 |
| `danger` | `ink` | `wax` 2px + 텍스트 `wax` | 소생 · 확정 · 되돌릴 수 없는 것 |

라운딩 0. 그림자 없음. **2px 하드 엣지만으로 깊이를 만든다.**
레퍼런스의 상단 액자처럼 **이중선(바깥 `bone` 2px + 안쪽 1칸 띄우고 `dust` 2px)** 은 HUD 에만 쓴다.

## 3. 텍스트 규칙 (v3.1)

| 용도 | 색 | 크기 | 예 |
|---|---|---|---|
| 대사 · 제목 | `bone` | **48px** | `...강한 무기 있나요?` |
| 본문 · 수치 | `bone` | **32px** | `12,840 G`, `84.2 K` |
| 라벨 · 보조 | `dust` | **16px** | `GOLD` `FANS` `REPUTATION` |
| 강조/위험 | `wax` | 32px | 비용, 경고, `LIVE`, 평판 등급 |

크기는 **16 / 32 / 48 세 단계뿐**이다 (01-ARCHITECTURE §5 — 네오둥근모 native 16px 의 정수배).
골드 전용색(`tallow`)과 소생실 전용색(`spirit`)은 **폐기**됐다. 금액도 `bone` 으로 쓴다.

### 한글 줄바꿈
Phaser의 `wordWrap`은 공백 기준이라 한글에서 어색하다.
→ `ui/wrap.ts`에 **글자 수 기반 래퍼** 구현: 32px 본문 기준 반각 16px / 한글 32px 로 카운트한다 (라벨 16px 은 절반).
문장 부호가 줄머리에 오지 않게 하는 간단한 금칙 처리 포함.

## 4. 커서

기본 커서를 **봉랍 도장 모양**으로 교체한다.
```css
#game canvas { cursor: url('assets/packs/placeholder/ui/cursor.png') 4 4, pointer; }
```
클릭 가능 요소 위에서는 도장이 **살짝 기울어진** 두 번째 이미지로 바뀐다. 값싸고 효과가 크다.

## 5. 연출 프리셋 (`src/ui/fx.ts`)

| 이름 | 사양 |
|---|---|
| `shake(px, ms)` | 카메라 흔들림. 정수 픽셀 단위만 |
| `signalLost(ms)` | **지지직 노이즈.** 스캔라인 침입 → 흑백 디더 노이즈 → 가로 찢김 → 암전 |
| `flashWax(ms)` | 화면 전체 `wax` 알파 0.35 → 0 |
| `hitStop(ms)` | 8~12ms 프레임 정지 (봉랍 임팩트용) |
| `numberPop(x,y,'+340G')` | 위로 48px 떠오르며 페이드. `bone` |
| `dither(from,to,ms)` | 디더 패턴 전환. 씬 전환 전용 |

### 씬 전환은 **디더 와이프** 하나로 통일
페이드(알파)를 쓰면 팔레트가 깨져 픽셀 느낌이 사라진다. 4×4 베이어 디더 패턴을 임계값 애니메이션으로 처리. 셰이더 없이 타일 스프라이트 마스크로도 충분하다.

## 6. 접근성 & 심사자 배려 (옵션 메뉴) — v3

- `연출 감소` — 화면 흔들림 / 플래시 / 노이즈 off. **지체 페널티도 함께 꺼진다**
- `속도` 1x / 1.5x / 2x — 층 이동·연출 재생 속도 (전투 대기에는 영향 없음)
- `튜토리얼 힌트 표시`

**`타이머 끄기` 항목은 삭제한다** — v3에는 제한시간 자체가 없다.

**옵션 메뉴는 P1이 아니라 P0에 가깝다.** 심사자가 30초 만에 막히면 점수가 없다.

## 7. 첫 30초 온보딩 (필수)
