# 04 · UI 킷 & 레이아웃 상수

> Phaser로 UI를 만들 때 매번 좌표를 새로 정하면 6일 안에 화면이 절대 정돈되지 않는다.
> **모든 좌표는 이 문서의 상수를 쓴다.**

## 1. 레이아웃 상수 (`src/ui/layout.ts`)

```ts
export const L = {
  W: 480, H: 270,

  hud:    { x: 0,   y: 0,   w: 480, h: 26 },
  stage:  { x: 0,   y: 26,  w: 480, h: 244 },   // 단계별 본문 영역

  // ④ DIVE 전용
  tower:  { x: 0,   y: 26,  w: 288, h: 178 },
  chat:   { x: 288, y: 26,  w: 192, h: 178 },
  radio:  { x: 0,   y: 204, w: 480, h: 66 },

  // 공통 하단 액션 바
  actions:{ x: 0,   y: 226, w: 480, h: 44 },

  // 3칸 그리드 (진열대 / 캐스팅 / 검시 선택지)
  slot3:  { x: 24,  y: 70,  w: 136, h: 120, gap: 12 },

  pad: 6,
  line: 1,
} as const;
```

**슬롯 x 좌표 계산**: `L.slot3.x + i * (L.slot3.w + L.slot3.gap)` → 24, 172, 320. 우측 여백 24. 대칭.

### 2-1. Button 계약

```ts
new Button(scene, {
  x, y, w, h,
  label: '오른쪽이야',
  variant: 'default' | 'danger' | 'ghost',   // danger = wax 테두리
  onClick: () => store.dispatch({ type: 'RADIO/ANSWER', dir: 'RIGHT' }),
  hotkey?: '1' | '2' | '3',                  // 숫자키 지원 (심사자 편의)
});
```

**모든 주요 선택지에 숫자 핫키를 붙인다.** 데모 영상 촬영과 심사자 조작이 빨라진다.

### 2-2. Panel 스타일 2종

| variant | 채움 | 테두리 | 용도 |
|---|---|---|---|
| `raised` | `clay` | 상/좌 `line` 밝게, 하/우 `soot` | 카드, 버튼 |
| `sunken` | `ash` | 상/좌 `soot`, 하/우 `line` | 목록, 채팅창, 입력 영역 |

라운딩 0. 그림자 없음. **1px 하드 엣지만으로 깊이를 만든다.**

## 3. 텍스트 규칙

| 용도 | 색 | 크기 | 예 |
|---|---|---|---|
| 본문 | `bone` | 16px | 대사, 설명 |
| 보조 | `dust` | 16px | 층수 라벨, 수치 단위 |
| 강조/위험 | `wax` | 16px | 비용, 경고, LIVE |
| 골드 | `tallow` | 16px | `+340 G` |
| 부활 | `spirit` | 16px | 소생실 UI 전용 |

폰트 크기는 **16px 단일**이다 (01-ARCHITECTURE §5). 위계는 색과 여백으로 만든다.

### 한글 줄바꿈
Phaser의 `wordWrap`은 공백 기준이라 한글에서 어색하다.
→ `ui/wrap.ts`에 **글자 수 기반 래퍼** 구현: 폭(px) ÷ 8px(반각 기준) 로 계산, 한글 1자 = 16px로 카운트.
문장 부호가 줄머리에 오지 않게 하는 간단한 금칙 처리 포함.

## 4. 커서

기본 커서를 **봉랍 도장 모양**으로 교체한다.
```css
#game canvas { cursor: url('assets/packs/placeholder/ui/cursor.png') 4 4, pointer; }
```
클릭 가능 요소 위에서는 도장이 **살짝 기울어진** 두 번째 이미지로 바뀐다. 값싸고 효과가 크다.

## 5. 연출 프리셋 (`src/ui/fx.ts`)

| 이름 | 사양 |
|---|---|
| `shake(px, ms)` | 카메라 흔들림. 정수 픽셀 단위만 |
| `flashWax(ms)` | 화면 전체 `wax` 알파 0.35 → 0 |
| `hitStop(ms)` | 8~12ms 프레임 정지 (봉랍 임팩트용) |
| `numberPop(x,y,'+340G')` | 위로 12px 떠오르며 페이드. `tallow` |
| `dither(from,to,ms)` | 디더 패턴 전환. 씬 전환 전용 |

### 씬 전환은 **디더 와이프** 하나로 통일
페이드(알파)를 쓰면 팔레트가 깨져 픽셀 느낌이 사라진다. 4×4 베이어 디더 패턴을 임계값 애니메이션으로 처리. 셰이더 없이 타일 스프라이트 마스크로도 충분하다.

## 6. 접근성 & 심사자 배려 (옵션 메뉴)

- `타이머 끄기` — 모든 소프트 타이머 무한
- `연출 감소` — 화면 흔들림/플래시 off
- `속도` 1x / 1.5x / 2x — 하강 시뮬 재생 속도
- `튜토리얼 힌트 표시`

**옵션 메뉴는 P1이 아니라 P0에 가깝다.** 심사자가 30초 만에 막히면 점수가 없다.
