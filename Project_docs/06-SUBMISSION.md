- 팔레트 9색만. 텍스트는 `bone` + `wax`
- 1280×720 로 만들고 480×270 도트 확대 느낌 유지 (정수배)

## 6. `Project_docs/CODEX_LOG.md` — 가산점 문서

심사 항목에 「Codex 협업」이 있다. 개발하면서 **실시간으로** 기록한다. 나중에 쓰려면 못 쓴다.

기록 형식:
```md
## D1 · M02 코어 상태머신
**프롬프트**: (실제로 넣은 프롬프트 전문)
**산출**: reducer.ts 420줄, 테스트 12개
**수정한 것**: rngCursor 처리가 순수하지 않아 직접 고침
**배운 것**: 모듈 문서를 먼저 주면 재작업이 거의 없다
```

**"AI가 다 짜줬다"가 아니라 "문서 → 모듈 → 검증 루프를 설계했다"** 로 서술한다.
우리 프로젝트는 `Project_docs/modules/*.md` 12개가 그 자체로 증거물이다. 이게 강점이다.
