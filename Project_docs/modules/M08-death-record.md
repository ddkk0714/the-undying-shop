## 목적
**사망은 실패가 아니라 하이라이트다.** 이 단계는 순수하게 도파민 장치다.

## 흐름 (10초) — v3: 앞에 노이즈가 붙는다

사망 판정은 **③ 생방송에서 용사 HP가 0이 될 때** 일어난다. 이 단계는 그 직후를 받는다.

```
[생방송 마지막] 용사 HP 0
t=0.00  hitStop 150ms — 전체 정지
t=0.15  전투 화면에 스캔라인 침입 (2프레임)
t=0.35  ★ 지지직 — 흑백 디더 노이즈 + 가로 찢김 8프레임. 채팅이 폭주하다 끊긴다
t=1.20  암전. 낮은 험 소리만 남는다
─────── 여기서부터 ④ DEATH 단계 ───────
t=1.80  텍스트: "리온 · 31F 사망"
        사인:  "불길에 삼켜졌다"
t=3.00  ★ 기록 갱신이면 → RECORD_BREAK 연출 (아래)
t=5.50  일일 정산 요약
t=10.0  → AUTOPSY
```

**노이즈는 팔레트 3색(`soot` `dust` `bone`)만 쓴 디더 패턴으로 만든다.** 셰이더 불필요.
**소리가 절반이다** — 방송 끊김음 + 저역 험. 이 2초가 데모 영상에서 가장 많이 회자될 구간이다.

## RECORD_BREAK 연출 — 아끼지 마라

```
     ┌──────────────────────────┐
     │                          │
     │    N E W   R E C O R D   │  ← bone, 자간 넓게
     │                          │
     │         3 1 F            │  ← wax, 큰 글씨(16px를 스프라이트로)
     │                          │
     │    이전 기록 · 28F        │  ← dust
     └──────────────────────────┘
       화면 전체 wax 플래시 3회
       카메라 흔들림 4px
       채팅 폭주 (HYPE 톤 12줄 동시)
       슈퍼챗 200~400G 연쇄
       HUD 게이지 31/40 으로 차오름
```

- 지속 2.5초. 스킵 가능(클릭)
- **이 연출이 데모 영상의 클라이맥스다.** 3분 영상 시나리오에서 반드시 들어간다

## 일일 정산 요약 (4초)

```
┌ DAY 3 종료 ──────────────────────┐
│  도달        31F   (신기록)       │
│  슈퍼챗    +1,240 G               │
│  장비 판매 +1,960 G               │
│  굿즈      +  410 G               │
│  ─────────────────────            │
│  오늘 수입 +3,610 G               │
│  팬        84.2K → 91.7K  (+7.5K) │
└──────────────────────────────────┘
```

숫자는 **하나씩 순차적으로** 카운트업된다(각 0.3초). 한 번에 다 뜨면 감흥이 없다.

## 팬 변동 계산

```
fansDelta = base × depthMul × dramaMul × (1 - viewerFatigue/100)

base       = 800
depthMul   = 1 + (diedFloor - 15) × 0.08          // 얕으면 마이너스
dramaMul   = 1 + (신기록 ? 1.5 : 0)
               + (거짓말로 얕게 죽음 ? -0.4 : 0)
               + (appealCount × 0.06)              // v3: 어필이 많았던 방송일수록 여운이 크다
```

**어필은 이중으로 팬을 준다** — 그 순간 즉시(M06), 그리고 사망 정산에서 한 번 더.
그래서 「오늘 벌고 내일 갚는다」가 성립한다.

**28F 이후 `viewerFatigue`가 오르면 이 식의 마지막 항이 팬 증가를 잡아먹는다.**
플레이어는 "왜 더 깊이 갔는데 팬이 안 늘지?" 를 체감한다. 설명하지 않는다.

## 수용 기준
- [ ] 사망 연출이 8초 안에 끝나고 스킵 가능
- [ ] 신기록 시 게이지가 `n/40`으로 차오르는 애니메이션
- [ ] 정산 숫자가 순차 카운트업
- [ ] 얕은 층 사망 시 팬이 실제로 **감소**한다 (음수 delta 확인)
- [ ] 28F 통과 이후 팬 증가폭이 눈에 띄게 둔화
- [ ] 지지직 노이즈가 재생되고 클릭으로 스킵 가능하다
- [ ] 노이즈에 팔레트 9색 밖의 색이 쓰이지 않는다
- [ ] `appealCount`가 많은 런일수록 팬 정산이 크다 (시뮬 확인)
