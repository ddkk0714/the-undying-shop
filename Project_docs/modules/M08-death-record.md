## 목적
**사망은 실패가 아니라 하이라이트다.** 이 단계는 순수하게 도파민 장치다.

## 흐름 (8초)

```
t=0.0  hitStop 120ms — 화면이 멈춘다
t=0.12 flashWax — 화면 전체가 붉게 번쩍
t=0.3  실루엣이 무너지는 4프레임

       사인:  "불길에 삼켜졌다"

t=4.0  일일 정산 요약
t=8.0  → AUTOPSY
```

## RECORD_BREAK 연출 — 아끼지 마라

```
     ┌──────────────────────────┐
     │                          │
     │    N E W   R E C O R D   │  ← bone, 자간 넓게
     │                          │
     │         3 1 F            │  ← wax, 큰 글씨(16px를 스프라이트로)
     │                          │
     │    이전 기록 · 28F        │  ← dust
     └──────────────────────────┘
       화면 전체 wax 플래시 3회
       카메라 흔들림 4px
       채팅 폭주 (HYPE 톤 12줄 동시)
       슈퍼챗 200~400G 연쇄
       HUD 게이지 31/40 으로 차오름
```

- 지속 2.5초. 스킵 가능(클릭)
- **이 연출이 데모 영상의 클라이맥스다.** 3분 영상 시나리오에서 반드시 들어간다

## 일일 정산 요약 (4초)

```
┌ DAY 3 종료 ──────────────────────┐
│  도달        31F   (신기록)       │
│  슈퍼챗    +1,240 G               │

│  ─────────────────────            │

│  팬        84.2K → 91.7K  (+7.5K) │
└──────────────────────────────────┘
```

숫자는 **하나씩 순차적으로** 카운트업된다(각 0.3초). 한 번에 다 뜨면 감흥이 없다.

## 팬 변동 계산

```
fansDelta = base × depthMul × dramaMul × (1 - viewerFatigue/100)

base       = 800
depthMul   = 1 + (diedFloor - 15) × 0.08     // 얕으면 마이너스
dramaMul   = 1 + (신기록 ? 1.5 : 0) + (거짓말로 얕게 죽음 ? -0.4 : 0)
```

**28F 이후 `viewerFatigue`가 오르면 이 식의 마지막 항이 팬 증가를 잡아먹는다.**
플레이어는 "왜 더 깊이 갔는데 팬이 안 늘지?" 를 체감한다. 설명하지 않는다.
