## 채팅 톤 5종

| tone | 색 | 빈도 | leakPower | 삭제 대상 |
|---|---|---|---|---|
| `HYPE` | `bone` | 40% | 0 | ✕ |
| `CASUAL` | `dust` | 30% | 0 | ✕ |
| `DOUBT` | `dust` | 15% | 1 | △ |
| `TRUTH` | **`wax`** | 상황 의존 | 5~10 | **○** |
| `SUPERCHAT` | `tallow` | 이벤트 | 0 | ✕ |

`TRUTH` 톤만 눈에 띄게 `wax` 색이다. **플레이어가 0.3초 안에 발견할 수 있어야 한다.**

## 인터랙션

- 각 메시지 우측에 `[X]`(삭제) `[🚫]`(차단) 아이콘 — **`TRUTH`/`DOUBT` 톤에만** 표시
- 클릭 판정 영역은 아이콘보다 **넉넉하게 (최소 16×16)** — 480×270에서 정밀 클릭은 고통이다
- 메시지 수명 6초, 최대 동시 표시 7줄, 아래에서 위로 스크롤
- 풀링 12개. 매 프레임 텍스트 객체 생성 금지

| 행동 | 효과 |
|---|---|
| **삭제** | 해당 메시지 leak 무효화. `moderationCount++` |
| **차단** | 해당 닉네임이 이번 런 내내 등장 안 함. `moderationCount += 2` |
| **방치** (6초 경과) | `leak += leakPower` |

### 과잉 삭제 역풍
```
if (moderationCount > 5) {
  // 3초마다 MODERATION_BACKLASH 라인 강제 삽입
  reputation -= 1 per extra deletion
}
```
> 진실을 눈치챈 댓글은 지운다. 안 지우면 퍼진다. **너무 지우면 그것대로 의심받는다.**

이 두 방향의 압박이 동시에 존재하는 게 핵심이다. 한쪽만 있으면 그냥 클릭 노동이다.

## 슈퍼챗

### 발생 조건 (랜덤 아님 — 극적 순간에만)
| 트리거 | 금액 범위 |
|---|---|
| 갈림길에서 위험한 쪽 선택 | 40~120 G |
| 신기록 층 갱신 | 200~400 G |
| 사망 순간 | 80~250 G |
| **어필하기 선택** | **120~320 G (확정 발생)** |
| 목격 이벤트(18/23/28F) | 150~350 G |

```
amount = base × (1 + fans/100000) × (1 + charisma×0.05) × payPoolMul
```

### 팬 지불 여력 풀 (`payPool`)
- 하루 시작 시 `payPool = fans × 0.004` G
- 슈퍼챗이 나올 때마다 소모. 고갈되면 `payPoolMul`이 0.2까지 감소
- **매일 슈퍼챗을 짜내면 다음날 마른다.** 팬은 무한 지갑이 아니다

### 연출
`tallow` 색 `+340 G` 텍스트가 채팅창에서 튀어나와 HUD의 GOLD로 날아가 흡수 + 짧은 동전 소리.
**이게 이 게임의 초 단위 도파민이다.** 연출을 아끼지 마라.

## leak → 플레이어에게 보여주는 방법 (수치 비공개)

| leak | 채팅 변화 |
|---|---|
| 0~29 | `TRUTH` 톤 거의 안 나옴 |
| 30~49 | `TRUTH` 발생률 상승, `DOUBT` 증가 |
| 50~69 | `TRUTH`가 여러 줄 연달아, 서로 대화하기 시작 |
| 70+ | 채팅 전체가 `TRUTH` 톤으로 물듦. **삭제해도 계속 나온다** |

70을 넘으면 삭제가 무의미해진다. 이게 "손 쓸 수 없음"을 시스템으로 전달하는 방법이다.

## 수용 기준
- [ ] 초당 1.5~2개 속도로 메시지가 흐른다 (밀도)
- [ ] 어필 선택 시 `APPEAL` 톤 라인과 슈퍼챗이 확정 발생한다
- [ ] 선택 대기 3초를 넘기면 `SLOW` 톤 라인이 섞여 나온다
- [ ] `TRUTH` 톤이 `wax` 색이라 즉시 눈에 띈다
- [ ] 방치 6초 후 leak 증가, 삭제 시 증가 없음
- [ ] 6회 이상 삭제 시 역풍 라인이 등장하고 평판이 깎임
- [ ] 슈퍼챗이 극적 순간에만 발생하고 payPool이 고갈된다
- [ ] leak 70 이상에서 삭제해도 TRUTH가 계속 나온다
- [ ] 텍스트 객체가 12개를 초과 생성되지 않는다 (프로파일러 확인)
