## 시뮬레이션 흐름 (30초)

```
t=0    입장 연출 (1.5s)   "리온, 하강 시작합니다"
t=1.5  자동 하강           1층당 0.35s, 층 번호가 올라가며 카메라 스크롤
       ├ 갈림길 도달 → 일시정지 → 무전 (최대 5초 대기)
       ├ 위험 판정 → 즉사 가능
       └ 목격 층(18/23/28) 도달 → 유언 텍스트 + 카메라 정지 1.2s
t=30   또는 사망 시점 → DEATH 단계로
```

- 하강은 **자동**이다. 플레이어는 갈림길에서만 개입한다.
- 갈림길은 런당 **3~4회**. 층 간격은 `floors.json`의 그래프가 결정.
- 재생 속도 옵션 1x / 1.5x / 2x (심사자용)

## 3가지 답변의 결과

| 답변 | 즉시 효과 | 지연 효과 |
|---|---|---|
| **진실을 말함** | 스타가 그 길로 감 | 깊이 도달 → 수입↑, 목격↑, 소생비↑ |
| **거짓말** | 스타가 반대 길로 감 | **다음날 그 스타가 부활하면 무전에서 언급한다** |
| **나도 몰라** | 50% 랜덤 | 팬 -0.5%, 채팅에 *"사장 왜 저럼"* 라인 생성 |

### 지연된 죄책감 — 이 게임 최고의 장치
거짓말한 스타를 **되살리면**, 다음 방송의 첫 무전에서 이렇게 말한다:

> 📻 *"사장님, 어제 그 왼쪽 길이요. 막혀 있던데요."*
> *"...알고 계셨어요?"*

플레이어는 아무 대답도 할 수 없다. 선택지가 없다. 그냥 다음 갈림길로 넘어간다.
**훼손하면 이 대사가 나오지 않는다.** 여기서 플레이어는 처음으로 "죽여서 지우는 게 편하다"를 몸으로 배운다.

`content/radio.ko.json`에 `lieCallback` 배열 5종 준비.

## 위험 판정

```
deathChance(floor) = baseRisk(floor) × fork.risk × (1 - grit×0.06) × degradeMul
baseRisk(floor)    = 0.04 + max(0, floor - 20) × 0.012
```
- 매 층 판정. `targetCeiling`을 넘어서면 `deathChance`가 급증(×3)
- **반드시 죽는다.** `targetCeiling + 3`층에 도달하면 강제 사망
- 사망 원인은 `hazard`에서 문구 생성: `FLAME → "불길에 삼켜졌다"` 등

## 목격 이벤트 (18 / 23 / 28F)

해당 층을 처음 통과하면 하강이 1.2초 멈추고 화면 중앙에 `bone` 텍스트:

| 층 | 대사 |
|---|---|
| 18F | *"아래에 밭이 있었다. 누가 가꾸고 있었다."* |
| 23F | *"마왕은 우리를 공격하지 않았다. 문 앞에 서 있기만 했다."* |
| 28F | *"저건 사람이다. 우리랑 똑같이 생겼어."* |

- `star.witnessed.push(floor)`
- 채팅에 즉시 `TRUTH` 톤 메시지 생성 (M07)
- 28F는 추가로 `viewerFatigue += 25` → **팬 증가율이 처음으로 꺾인다**

**28F 연출은 특별하게.** 카메라가 멈추고, 채팅이 3초간 완전히 조용해진 뒤 다시 흐른다. 침묵이 가장 강한 연출이다.

## 탑 단면도 렌더링 (비용 절감 설계)

풀 배경 아트를 만들지 않는다. **프로시저럴 타일**로 그린다.
- 층 1개 = 288×32 스트립, 6종 타일(`bg.tower` 스프라이트시트)을 시드로 조합
- 구역별 tint 4종: 상층(`clay`) / 중층(`ash`) / 심층(`soot`) / 문 근처(`wax` 미세 혼합)
- 스타는 96×120 실루엣 1종 + idle/walk 각 1루프

**아트 물량이 이걸로 1/10이 된다.** 6일 일정에서 이 결정이 승패를 가른다.
