## 1. 두 개의 한 줄

> **관전을 조작으로 바꾼다.** 플레이어만 진짜 지도를 보고, 용사에게 거짓말할 수 있다.
> **그리고 매 전투마다 묻는다 — 살릴 것인가, 볼거리를 만들 것인가.**

당신이 그 굴을 팠다. 진짜 지도를 아는 건 당신뿐이다.
그리고 계약서에 「방송 중 갑의 프로듀스에 따른다」고 적혀 있다. 그래서 그는 묻고, 따른다.

## 3. 흐름 — 시간 제한 없음

```
입장 연출 (1.5s)   "리온, 하강 시작합니다"
  ↓
[층 루프]  현재 층에서:
   · 인카운터 있음 → 전투 (턴제, 플레이어가 고를 때까지 대기)
   · 갈림길 있음   → 무전 (플레이어가 답할 때까지 대기)
   · 목격 층(18/23/28F) → 유언 연출 1.2s
   · 아무것도 없음 → 0.3s 자동 하강
  ↓
용사 HP 0  →  지지직 노이즈 →  ④ 사망 단계
```

**용사는 반드시 죽는다.** 언제 죽느냐만 플레이어가 조작한다.
런 길이는 보통 **60~150초**, 결정 횟수 **10~18회**. 깊이 갈수록 방송이 길어진다 — 그게 자연스럽다.

### 시간 제한 대신 — 「지체하면 시청자가 빠진다」

타이머 바를 두지 않는다. 대신 **선택 대기 3초가 지나면 초당 시청자가 빠져나간다.**

```
delayPenalty: 대기 3초 초과 시 초당 fans × 0.0015 감소 (한 선택당 최대 -8%)
```

- HUD 시청자 수가 **조금씩 내려가는 것**만 보인다. 경고 문구 없음
- 채팅에 `"사장 왜 이렇게 느림"` `"나 잘래"` 라인이 섞인다
- **압박은 있되 제한시간은 없다.** 심사자가 UI를 읽느라 늦어도 게임이 망가지지 않는다
- 옵션 `연출 감소`를 켜면 이 페널티도 꺼진다 (접근성)

## 4. 1인칭 전투 ★ 신규

### 4-1. 인카운터

- **3층마다 1회** 발생 (`floors.json`의 `encounterEvery`)
- 한 인카운터 = 적 1마리. 적 HP를 0으로 만들거나, 용사 HP가 0이 되면 끝
- 보통 3~6턴에 끝난다

### 4-2. 스탯

```ts
// 용사 (M03 Star + M05 장비)
hp    = 40 + grit × 6 + Σ item.hp
atk   =  6 + grit × 1 + Σ item.atk
def   =  2 +            Σ item.def
// 열화 배율(M03)이 hp/atk 에 곱해진다

// 적 (층 기반)
enemyHp  = 18 + floor × 1.6
enemyAtk =  5 + floor × 0.55
```

### 4-3. 3택 — 이 게임의 두 번째 심장

용사가 매 턴 묻는다. **플레이어가 고를 때까지 화면은 기다린다.**

| 선택 | 효과 | 대가 |
|---|---|---|
| **1 공격** | 적 HP `-= atk × (0.9~1.1)` | 적이 반격 (55% 확률) |
| **2 방어** | 이번 턴 받는 피해 `× 0.25` | 적 HP 안 깎임 = **턴 소모, 방송 지루함(팬 -소폭)** |
| **3 어필하기** | **팬 급증 + 슈퍼챗 확정 발생** | **55% 확률로 적 공격 `× 1.4`**, 적 HP 안 깎임 |

```
어필 효과:
  fansGain    = 300 × (1 + charisma × 0.08) × (1 + floor / 30)
  슈퍼챗      = 확정 1회 (M07 witness 등급)
  피해 확률   = 55%,  적중 시 enemyAtk × 1.4
```

**「어필하기」가 이 게임의 주제를 30초마다 반복한다.**
공격과 방어는 그를 살리는 선택이고, 어필은 그를 파는 선택이다.
검시실에서 한 번 겪는 딜레마를, 전투에서는 한 런에 열 번 겪는다.

### 4-4. 어필의 숨은 대가 — 진실이 새어나간다

**어필 중에는 카메라가 주변을 오래 비춘다.**
18F 이하에서 어필하면 → 목격 확률 상승 + 채팅 `TRUTH` 라인 발생 확률 ×1.5

```
if (floor >= 18 && choice === 'APPEAL') leakRisk *= 1.5;
```

돈이 되는 행동이 진실을 흘린다. 설명하지 않는다.

### 4-5. 용사 대사 (`radio.ko.json`)

턴 시작마다 용사가 상황에 맞는 한 줄을 던진다. **이게 3택의 맥락을 만든다.**

| 상황 | 예시 대사 |
|---|---|
| HP 여유 | *"사장님, 이 정도는 갑니다. 갈까요?"* |
| HP 절반 | *"좀... 버거운데요. 어떡할까요?"* |
| HP 위험 | *"사장님. 저 지금 죽으면 회수해주시는 거 맞죠?"* |
| 어필 직후 | *"이거면... 오늘 좀 벌었나요?"* |
| 열화 4+ | *"...제가 여기 왜 있죠?"* |

**HP 위험 대사가 이 게임에서 제일 아픈 줄이다.** 그는 계약을 믿고 있다.

## 5. 무전 — 갈림길 (v2 유지, 화면 위치만 이동)

지도 아래 무전기 패널에서 처리한다. **전투 중에는 무전이 오지 않는다.** 교대로 발생한다.

```
┌ 📻 무전기 ─────────────┐
│ 리온 · 22F              │
│ "갈림길인데요.          │
│  어느 쪽이에요?"        │
│ ─── 진짜 지도 ───       │  ← clay 배경 + line 테두리 (당신의 서랍)
│ ◀ 왼쪽  · 26F 붕괴위험  │
│ ▶ 오른쪽 · 31F 짐승소굴 │
│ [◀][▶][나도 몰라]      │
└─────────────────────────┘
```

- 갈림길은 런당 **3~4회**
- 좌/우의 좋고 나쁨은 **매 런 시드로 스왑**된다. 정답을 외울 수 없다
- 「나도 몰라」 → 50% 랜덤 + 팬 -0.5% + 채팅에 *"사장 왜 저럼"*

### 지연된 죄책감 — 이 게임 최고의 장치 (v2 유지)

거짓말한 용사를 **되살리면**, 다음 방송 첫 무전에서 이렇게 말한다:

> 📻 *"사장님, 어제 그 왼쪽 길이요. 막혀 있던데요."*
> *"...알고 계셨어요?"*

플레이어는 대답할 수 없다. 선택지가 없다. 그냥 다음 갈림길로 넘어간다.
**훼손하면 이 대사가 나오지 않는다.** 여기서 "죽여서 지우는 게 편하다"를 몸으로 배운다.

## 6. 좌측 층수 게이지 & 지도

### 층수 게이지 (26px 폭)
- 세로로 층 번호가 흐른다. **아래로 스크롤될수록 깊어진다**
- 현재 층은 `wax` 하이라이트
- 최고 기록 층에 `bone` 눈금 1개 — 넘어서는 순간 눈금이 부서진다

### 던전 지도 (124×134)
- **프로시저럴 타일.** 풀 배경 아트를 만들지 않는다
- 지나온 경로가 선으로 남고, 현재 위치는 깜빡이는 점
- **갈림길의 진짜 정보는 지도에 그리지 않는다** — 무전기 패널에만 텍스트로 뜬다
  (지도에 다 보이면 무전이 무의미해진다)

## 7. 초상화 — 상태에 따라 변한다

우상단 144×100. **이 게임에서 가장 값싸고 효과적인 연출이다.**

| 상태 | 표현 |
|---|---|
| HP 100~70% | 평상 |
| HP 70~40% | 땀, 눈썹 처짐 |
| HP 40~15% | 피, 호흡 |
| HP 15% 이하 | 초점 없음. **화면이 미세하게 흔들린다** |
| 어필 중 | 억지 웃음 + 카메라를 본다 ← **가장 중요한 컷** |
| 열화 3+ | 위 모든 상태에 균열 오버레이 |

**「어필 중」 초상만큼은 반드시 따로 그려라.** 그 한 장이 이 게임의 썸네일이다.

## 8. 사망 → 지지직 노이즈 (신규)

용사 HP가 0이 되면:

```
t=0.00  hitStop 150ms — 전체 정지
t=0.15  전투 화면에 노이즈 스캔라인 침입 (2프레임)
t=0.35  화면 전체가 지지직 — 흑백 노이즈 + 가로 찢김 8프레임
        채팅이 폭주하다 끊긴다
t=1.20  화면 암전, 낮은 험 소리만 남음
t=1.80  → ④ 사망 단계 (M08)
```

- 노이즈는 팔레트 3색(`soot` `dust` `bone`)만 쓴 디더 패턴으로 만든다. 셰이더 불필요
- **소리가 절반이다.** 방송 끊김음 + 저역 험

## 9. 목격 이벤트 (18 / 23 / 28F) — v2 유지

처음 통과 시 하강이 1.2초 멈추고 `bone` 텍스트:

| 층 | 대사 |
|---|---|

침묵이 가장 강한 연출이다. 그리고 `viewerFatigue += 25`.

## 11. 수용 기준

**전투**
- [ ] 3층마다 인카운터가 발생하고, 3~6턴에 끝난다
- [ ] 공격/방어/어필이 각각 다른 결과를 낸다 (테스트 3개)
- [ ] 어필 시 팬이 실제로 급증하고 슈퍼챗이 확정 발생한다
- [ ] 어필 시 55% 확률로 큰 피해를 받는다 (1000회 시뮬로 분포 확인)
- [ ] 18F 이하에서 어필하면 leak 위험이 1.5배가 된다
- [ ] 용사 HP가 0이 되면 반드시 사망 단계로 넘어간다

**시간 제한 없음**
- [ ] 어떤 선택에도 타이머 바가 없다
- [ ] 3초 이상 대기하면 시청자 수가 조금씩 줄어든다 (HUD에서 보인다)
- [ ] 옵션 `연출 감소`를 켜면 지체 페널티가 꺼진다
- [ ] 10분을 가만히 둬도 게임이 진행되거나 망가지지 않는다

**무전**
- [ ] 갈림길 3~4회, 진짜 지도가 무전기 패널에만 보인다
- [ ] 지도 영역에는 갈림길 정답이 그려지지 않는다
- [ ] 거짓말 후 그 용사를 부활시키면 다음 런 첫 무전에서 콜백 대사가 나온다
- [ ] 훼손한 경우 콜백이 나오지 않는다
- [ ] 전투 중에는 무전이 오지 않는다

**화면**
- [ ] 5분할 좌표가 `L.live` 상수와 정확히 일치한다
- [ ] 초상화가 HP 구간·어필·열화에 따라 바뀐다
- [ ] 28F 통과 시 채팅이 3초 정지 후 재개
- [ ] 사망 시 지지직 노이즈가 재생되고 스킵 가능하다
- [ ] 헤드리스 시뮬(M02)에서 이 모듈이 Phaser 없이 동작한다
