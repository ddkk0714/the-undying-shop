## 2. 계약이란 무엇인가 (세계관)

용사가 당신을 찾아오는 이유는 하나다. **당신에게 맡기면 시체가 돌아오기 때문이다.**

```
┌ 전 속 계 약 서 ────────────────────────┐
│                                        │
│  갑(회수상)은 을(용사)의 시체를          │
│  층수와 상태를 불문하고 회수한다.        │
│                                        │
│  을은 그 대가로,                        │
│  방송 중 갑의 프로듀스에 따른다.         │
│                                        │
└────────────────────────────────────────┘
```

이 한 줄이 **무전 시스템의 법적 근거**다. 왜 용사가 갈림길에서 굳이 물어보는가 — 계약이기 때문이다.
그리고 왜 당신이 거짓말을 해도 그가 따르는가 — **계약이기 때문이다.**

**진실 층위에서 보면**: 마왕이 300년간 인간과 맺어온 거래의 축소판이다. 죽지 않게 해줄 테니 내려가라.

---

## 3. 계약서 (`Contract`)

용사가 **직접 작성해서 제출**한다. 즉 **자기 신고 자료**다.

```
┌ 계 약 서 ──────────────────── 제출 ─┐
│                                      │
│  이름      세라                      │
│  인지도    C  (팬 1,200)             │
│                                      │
│  ─ 공략 가능 층 ─                    │
│    21F 까지    100 %                 │
│    25F 까지     75 %                 │
│    31F 까지     25 %                 │
│                                      │
│  ─ 요구 사항 ─                       │
│    계약금 1,200 G                    │
│                                      │
│        [ 계약한다 ]  [ 돌려보낸다 ]   │
└──────────────────────────────────────┘
```

### 핵심: **이 숫자는 사실이 아닐 수 있다**

```ts
export interface Contract {
  starId: StarId;
  claimedTiers: { floor: number; rate: number }[];  // 자기 신고 (플레이어가 보는 것)
  fee: number;                                       // 계약금
  /** 실제 실력과의 괴리. 플레이어에게 절대 노출 금지 */
  honesty: number;   // 0.6 ~ 1.3. 1.0 미만 = 과장, 초과 = 겸손
}
```

- `honesty < 0.85` → **과장형.** 계약서보다 훨씬 얕은 층에서 죽는다
- `honesty > 1.15` → **겸손형.** 싸게 데려왔는데 잘한다. 발굴의 쾌감
- 플레이어는 계약서만 본다. 진실은 **첫 방송에서 드러난다**

### 과장을 알아채는 단서 (설명하지 않는다)
| 단서 | 의미 |
|---|---|
| 계약금이 인지도에 비해 높다 | 과장 가능성 |
| 확률 곡선이 너무 완만하다 (100→95→90) | 과장 가능성 |
| 인지도가 F인데 31F를 25%로 적었다 | 거의 확실한 과장 |

**이것이 이 게임의 두 번째 거짓말이다.** 플레이어는 무전으로 거짓말하고, 용사는 계약서로 거짓말한다.

## 5. 진열대 = 판매 = 무장 (v2에서 유지)

> **진열대에 올린 장비는 즉시 판매되어 골드가 들어오고, 동시에 오늘 출연자의 전투 능력이 된다.**

파는 것과 무장시키는 것이 같은 행위다. 용사는 당신 가게에서 장비를 사가기 때문이다.
그리고 부활한 본인은 기억이 없어서, **자기가 어제 쓰던 물건을 오늘 다시 산다.**

툴팁 한 줄로만 알려준다:
> *「리온이 어제 이걸 사갔다. 오늘도 처음 보는 얼굴로 산다.」*

### v3 변경 — 장비가 「도달 층 +N」이 아니라 **전투 스탯**을 준다

전투가 1인칭 턴제로 바뀌었으므로 장비도 전투 수치를 준다.

```ts
export interface ItemDef {
  id: ItemId;
  name: string;
  iconKey: string;
  hp: number;        // 최대 체력 보너스
  atk: number;       // 공격력
  def: number;       // 방어력
  price: number;     // 진열 시 즉시 들어오는 골드
  tier: 'S'|'A'|'B'|'C'|'F';
  isRelic: boolean;  // 시체에서 나온 유품인가
}
```

### 진실 유품 2종 — 그대로 유지
`soil_deep`(아래의 흙), `page_torn`(찢어진 낱장)은 **전투 능력이 0**이다. 오직 돈이다.
- 28F 이하에서만 드랍
- **판매 시 `leak +10`** — 누군가 그걸 보고 이상하게 여긴다
- 팔지 않으면 leak 0. 하지만 돈이 없다
- 툴팁: *「흙이 젖어 있다. 이 아래에는 물이 있다.」*

**비용 대비 효과가 가장 큰 콘텐츠다. 반드시 넣어라.**

## 6. 유품 순환 (v2 유지)

훼손한 시체에서 나온 유품이 인벤토리로 들어온다. **매입비 0.** 유일한 재고 공급원이다.
→ 훼손을 안 하면 팔 물건이 마른다. **훼손 압박이 경제적으로도 걸린다.**

---

## 7. 미출연 페널티 (v2 유지)
연속 2일 이상 출연하지 않은 페르소나는 하루당 `fandom -3%`. 전부를 쉬게 할 수는 없다.

## 8. 수용 기준
- [ ] 방문자가 있는 날에만 모드 A가 뜨고, 없으면 바로 모드 B로 간다
- [ ] 계약서의 층별 확률이 `honesty`와 무관하게 표시된다 (플레이어는 진실을 모른다)
- [ ] `honesty` 값이 UI 어디에도 노출되지 않는다 (grep으로 확인)
- [ ] 과장형(`honesty < 0.85`) 용사가 실제로 계약서보다 얕은 층에서 죽는다 (시뮬 검증)
- [ ] 돌려보낸 용사는 이후 다시 등장하지 않는다
- [ ] 계약금이 골드에서 즉시 차감된다
- [ ] 진열 확정 시 골드가 즉시 증가하고 출연자의 HP/ATK/DEF가 갱신된다
- [ ] 진실 유품 2종 판매 시 `leak`이 오른다
- [ ] 캐스팅 3칸 + 진열 3칸 모두 숫자 핫키로 조작 가능
