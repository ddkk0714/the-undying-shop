## ② 캐스팅 (~10초)

### 목적
"오늘 누구를 죽일 것인가"를 고르게 한다. 표현은 "누구를 내보낼 것인가"다.

### 화면 — 3칸 카드
```
   오늘의 출연자를 선택하시오
┌──────────┐ ┌──────────┐ ┌──────────┐
│ [초상]    │ │ [초상]    │ │ [초상]    │
│ 불꽃의    │ │ 무명      │ │ (신인)    │
│  리온 4대 │ │           │ │  세라     │
│ 팬 10.5K  │ │ 팬 0.9K   │ │ 팬 0     │
│ 열화 ▓▓▓░ │ │ 열화 ░░░░ │ │ 열화 ░░░░│
│ 적정 ~28F │ │ 적정 ~19F │ │ 적정 ~22F│
└──────────┘ └──────────┘ └──────────┘
      [1]          [2]          [3]
```

### 표시 정보 (4개만)
1. 페르소나 이름 + 대수
2. 팬덤 규모
3. 열화 게이지 (숫자 아님, 4칸 바)
4. **적정 층** = `f(grit, luck, 열화)` — "이 정도까지는 무난하다"는 힌트

### 선택이 만드는 차이
| 요소 | 영향 |
|---|---|
| 팬덤 큼 | 슈퍼챗·굿즈 수입↑, **죽었을 때 팬 이탈 충격도 큼** |
| 열화 심함 | 얕은 층에서 죽음, 하지만 소생비도 이미 비쌈 → 폐기 압박 |
| 신인 | 싸고 안전, 하지만 수입이 거의 없음 |

### 미출연 페널티
연속 2일 이상 출연하지 않은 페르소나는 하루당 `fandom -3%`.
**전부를 쉬게 할 수는 없다.**

## ③ 진열대 (~12초)

### 목적
"오늘 얼마나 깊이 보낼 것인가"를 **돈으로** 결정하게 한다.

### 화면 — 3칸 슬롯 + 인벤토리
```
   진열대                     오늘의 예상 도달  ~24F
┌──────────┐┌──────────┐┌──────────┐
│ 균열난    ││  (비움)   ││ 재의 망토 │
│  단검     ││          ││          │
│ 깊이 +4   ││          ││ 깊이 +7  │
│ 판매 620G ││          ││ 판매1,340G│
└──────────┘└──────────┘└──────────┘

인벤토리  ▸ 낡은 랜턴 +2 · 280G   ▸ 문지기의 이빨 +9 · 3,100G  ...
                                    [ 확정 ]  ▮▮▮▮▮▮▯ 12s
```

### 핵심 규칙 — 이게 이 게임 경제의 심장
> **진열대에 올린 장비는 즉시 판매되어 골드가 들어오고, 동시에 오늘 출연자의 도달 층을 올린다.**

즉 **파는 것과 무장시키는 것이 같은 행위다.**
왜냐하면 스타는 당신 가게에서 장비를 사가기 때문이다. 부활한 본인은 기억이 없어서, **자기가 어제 쓰던 물건을 오늘 다시 산다.**

이 사실을 툴팁 한 줄로만 알려준다:
> *「리온이 어제 이걸 사갔다. 오늘도 처음 보는 얼굴로 산다.」*

### 도달 층 계산
```
targetCeiling = baseFloor(star) + Σ(item.depth) + luckBonus
baseFloor(star) = 10 + grit × 1.2 × degradeMul
luckBonus       = round(luck × 0.5)
```

### 딜레마
- 좋은 장비를 올리면 → **골드 즉시 유입 + 깊이 도달 = 수입 극대화**
- 그런데 깊이 가면 → **진실을 목격하고, 소생비가 폭등한다**
- 아무것도 안 올리면 → 골드도 없고 얕은 층에서 죽어 시청자도 없다

### 유품 순환
훼손한 시체에서 나온 유품(`isRelic: true`)은 인벤토리로 들어온다.
**매입비 0.** 이게 유일한 재고 공급원이다.
→ 훼손을 안 하면 팔 물건이 마른다. **훼손 압박이 경제적으로도 걸린다.**

**`soil_deep`(아래의 흙)과 `page_torn`(찢어진 낱장)은 진실 유품이다.**
- 28F 이하에서만 드랍
- 판매하면 큰돈이지만 **판매 시 `leak +10`** (누군가 그걸 보고 이상하게 여긴다)
- 팔지 않고 보관하면 leak 0, 하지만 돈이 없다
- 툴팁: *「흙이 젖어 있다. 이 아래에는 물이 있다.」*

이 두 아이템 하나로 "탐욕 vs 은폐" 딜레마가 진열대에도 생긴다. **비용 대비 효과가 가장 큰 콘텐츠다. 반드시 넣어라.**

## 수용 기준
- [ ] 캐스팅 3칸 + 숫자 핫키 1/2/3
- [ ] 열화 게이지가 숫자 없이 4칸 바로 표시
- [ ] 진열대 확정 시 골드가 즉시 증가하고 `targetCeiling`이 갱신
- [ ] 진실 유품 2종 판매 시 `leak`이 오른다
- [ ] 인벤토리가 비면 "팔 물건이 없습니다" 안내 + 도달층이 낮게 고정
- [ ] 미출연 2일차 페르소나의 팬덤이 실제로 감소
