```
        [문지기 일러스트 1컷 · 96×120 확대]

    문지기가 스타의 얼굴을 오래 들여다본다.
```

## 3. 엔딩 판정 (`ANNOUNCE` 종료 시점)

```ts
export function judgeEnding(s: GameState): EndingId | null {
  if (s.maxFloor >= 40)  return 'A_OPEN';
  if (s.day >= 8) return s.leak >= 70 ? 'B_REVEAL' : 'B_CONTINUE';
  return null;
}
```

### A · 개문 (40F 도달)
```
문이 열린다.

아래에서 빛이 올라온다. 물 냄새가 난다.
당신은 300년 만에 그 냄새를 맡는다.

지상은 이제 필요 없다.

     불꽃의 리온 ..... 사라짐
     무명       ..... 사라짐
     세라       ..... 사라짐
     일란       ..... 사라짐

     (당신의 스타 목록이 한 줄씩 지워진다)

가게에는 아무도 오지 않는다.
장부만 남았다.
```
- 스타 이름이 **1.2초 간격으로 한 줄씩** `soot` 색으로 덮인다
- 마지막에 봉랍 도장이 장부 위에 찍히고 끝

### B · 폭로 (leak ≥ 70)
```
마지막 스타가 문 앞에서 돌아선다.
방송은 아직 켜져 있다.

"여러분. 아래에는 마왕이 없습니다."
"밭이 있고, 물이 있고, 사람이 있습니다."
"우리랑 똑같이 생긴 사람이."

"그리고 저는... 제가 몇 번째인지 모르겠습니다."

     [ 방송을 끊는다 ]   [ 아무것도 하지 않는다 ]
```
- 어느 쪽을 골라도 끊기지 않는다. **버튼이 반응하지 않는다.**
- 3초 후 채팅창이 폭주하다가 정지하고 화면이 `soot`으로

### B-변형 · 계속 (leak < 70, Day 8 종료)
```
DAY 9

     소생실이 열린다.
     어제 죽은 스타를 살릴 것인가.

              (페이드아웃)
```
아무것도 밝혀지지 않는다. **그게 이 엔딩의 요지다.**
