## ⑥ 검시실 (~10초) — 비공개

18층 아래에서 죽은 스타를 **되살리면 그가 본 것을 방송에서 말한다.**

### 화면
```
┌ 검시실 ─────────────────── 비공개 ─┐
│                                     │
│      [시체 실루엣 · 31F 회수]        │
│                                     │
│  목격 기록                           │
│   · 18F  "아래에 밭이 있었다"        │
│   · 28F  "저건 사람이다"             │  ← wax 색
│                                     │
│  ┌───────────┐  ┌───────────┐       │
│  │  온 전     │  │  훼 손     │       │
│  │           │  │           │       │
│  │ 부활 가능  │  │ 유품 확보  │       │
│  │ 팬덤 유지  │  │ 승계 가능  │       │
│  │ 진실 보유  │  │ 진실 삭제  │       │
│  └───────────┘  └───────────┘       │
│      [1]            [2]              │
│                        ▮▮▮▮▮▯ 10s   │
└─────────────────────────────────────┘
```

### 2택 결과표

| 선택 | 얻는 것 | 잃는 것 |
|---|---|---|
| **온전** | 부활 가능, 팬덤 유지, 페르소나 유지 | **진실 보유 → 다음 방송에서 말한다 (leak +목격당 15~30)**, 소생비 발생 |
| **훼손** | 유품 2~3개 확보(재고!), 페르소나 승계 가능, **진실 완전 삭제** | 스타 상실, 팬덤 -15%, **회수 실패 공표 압박** |

### 훼손은 공짜 버튼이 아니다
훼손 자체는 무료지만 →
1. 스타를 잃는다 (다음날 캐스팅 옵션 감소)
2. **⑦에서 뭐라고 발표할지** 결정해야 한다
3. 실패 공표가 쌓이면 신인 풀이 마른다 (M03)

### 봉랍 연출
판정 확정 시:
- hitStop 120ms
- 붉은 도장이 화면 중앙에서 **쾅** (8프레임, 48×48 스프라이트)
- 화면 흔들림 3px + 저음 임팩트
- 시체 카드 위에 봉랍 자국이 남는다

**이 연출이 이 게임의 로고이자 시그니처다.** 여기에 시간을 써라.

## ⑦ 발표 (~5초) — 마지막 칼

검시 결과와 **다르게** 공표할 수 있다.

```
┌ 오늘의 공표 ────────────────────────┐
│                                      │
│  실제 : 온전히 회수됨   ← 당신만 안다 │
│                                      │
│  [ "회수 성공했습니다" ]              │
│  [ "회수에 실패했습니다" ]  ← 거짓말   │
│                             ▮▮▯ 5s  │
└──────────────────────────────────────┘
```

### 4가지 조합

| 실제 | 공표 | 결과 |
|---|---|---|
| 온전 | 성공 | 평범. 평판 +2, 소생 단계로 이어짐 |
| 온전 | **실패** | **은닉**: 몸이 `HIDDEN` 상태로 보관. 팬덤에서 사라짐. 소생비 없이 나중에 부활 가능. 평판 -5, `falseAnnouncements++` |
| 훼손 | 성공 | **거짓 성공**: 팬덤 유지되지만 다음날 "왜 안 나옴?" 채팅 폭증, leak +8 |
| 훼손 | 실패 | 정직. 평판 -5, `falseAnnouncements++`, 신인 풀 감소 |

### 「온전 → 실패 공표」가 이 게임에서 가장 어두운 수다
> **서류상 죽은 스타를 몰래 갖고 있는 것이다.**

- 팬덤에서는 사라졌으니 굿즈 수입 0
- 하지만 소생비를 내지 않고 몸을 보관한다
- 나중에 새 페르소나를 씌워 "신인"으로 데뷔시킬 수 있다
- **본인은 자기가 죽었다고 발표된 걸 모른다**

이 조합을 발견한 플레이어는 게임을 이해한 것이다. 튜토리얼로 알려주지 마라.

### 평판 등급 표시
```
0-19 F · 20-39 D · 40-54 C · 55-69 B · 70-84 A · 85-100 S
```
`B+` 같은 +/- 는 구간 상위 1/3에 붙인다. 초기값 62 → `B+`.
