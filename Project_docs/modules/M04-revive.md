## 비용 산식 (M10과 공유, 여기가 정본)

```
cost = round10( BASE × FLOOR_EXP^diedFloor × gradeMul × DEGRADE^reviveCount )

BASE       = 400
FLOOR_EXP  = 1.055
gradeMul   = { INTACT: 1.0, DAMAGED: 1.5 }
DEGRADE    = 1.4
reviveCount = 지금까지 부활한 횟수 (0부터)
```

### 검증 (원본 기획서 기준표와 일치해야 함)
| 상황 | 계산 | 결과 | 원본 목표 |
|---|---|---|---|
| 12F · 온전 · 1회차(n=0) | 400×1.055^12×1.0×1.4^0 | **760** | 800 ✅ |
| 24F · 훼손 · 3회차(n=2) | 400×1.055^24×1.5×1.4^2 | **4,250** | 4,200 ✅ |
| 31F · 훼손 · 5회차(n=4) | 400×1.055^31×1.5×1.4^4 | **12,120** | 12,000 ✅ |

**이 3행이 `economy.spec.ts`의 테스트 케이스다.** 산식을 바꾸면 이 표부터 다시 맞춰라.

## 3가지 선택

| 선택 | 비용 | 결과 |
|---|---|---|
| **되살린다** | cost | `reviveCount++`, 스탯 열화, 팬덤 유지, **목격한 진실을 다음 방송에서 말한다**(leak↑) |
| **그대로 둔다** | 0 | 시체 보관. 내일 다시 결정 가능하지만 **하루당 cost가 8% 증가**(부패) |
| **폐기** | 0 | 몸 소멸, 유품 확보, 페르소나 승계 가능, 팬덤 -15% |

**"그대로 둔다"의 8% 부패**가 결정을 미루지 못하게 만든다. 미루면 더 비싸진다.

## 목격 경고
소생 대상이 18F 이하를 목격했다면 화면에 `wax` 색으로:
> ⚠ *이 사람은 아래에서 무언가를 봤습니다. 되살리면 방송에서 말할 것입니다.*

이 경고가 **검시실(M09)과 짝을 이룬다.** 여기서 처음으로 플레이어는 "죽은 채로 두는 게 편할 수도" 라는 생각을 한다.

## 골드 부족 시
- `gold < cost` → 「되살린다」 버튼 비활성 + `wax` 텍스트 *"자금이 부족합니다"*
- 모든 스타가 죽어 있고 아무도 못 살리면 → 신인 풀에서 강제 캐스팅
- 신인 풀도 0이면 → **엔딩 B-변형(계속)** 으로 조기 종료. 게임오버 화면은 없다

## 연출
- 부활 확정 시: `spirit` 색 액체가 초상 아래에서 차오르는 8프레임 + 낮은 웅웅거림
- 폐기 확정 시: **봉랍 도장** + 화면 흔들림 2px + 초상이 `soot`으로 덮임
