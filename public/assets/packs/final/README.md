# 아트를 넣는 곳

**이 폴더에 PNG 를 넣으면 게임 그림이 바뀐다.** 코드도 JSON 도 건드릴 필요 없다.

```
1. 아래 표의 경로 그대로 이 폴더에 파일을 넣는다
2. 개발 서버를 재시작한다   (Ctrl+C → npm run dev)
```

끝이다. `npm run dev` 가 시작할 때 이 폴더를 알아서 훑는다 (`npm run build` 도 마찬가지다).

> **왜 새로고침만으로는 안 되나** — Vite 는 이 폴더의 파일 목록을 서버가 켜질 때 한 번만 읽는다.
> 그래서 켜진 뒤에 새로 넣은 그림은 서버가 아직 모른다. 재시작이 필요한 이유는 그것뿐이다.
>
> 서버가 켜진 채로 파일을 넣으면 **터미널이 즉시 알려준다** — 이름이 맞는지, 크기가 맞는지.
> 거기서 오타를 먼저 잡고 재시작하면 한 번에 끝난다.
> 서버 없이 확인만 하고 싶으면 `npm run art`.

넣지 않은 것은 **자동으로 플레이스홀더가 나온다.** 한 장만 넣어도 되고, 46장을 다 넣어도 된다.
중간에 하나가 없어도 게임은 절대 멈추지 않는다.

`npm run art` 는 무엇이 교체됐고 무엇이 아직 비었는지, **크기가 틀린 파일이 있는지** 표로 알려주고,
레포 최상단의 **`아트-발주서.xlsx` / `아트-발주서.csv` 를 다시 쓴다.**
그 파일에 아래 표가 「순서 · 구분 · 파일 · 크기 · 화면표시 · 설명 · 상태」로 정리돼 있다 —
그리는 사람에게는 그걸 건네면 된다. **「상태」열이 도착/대기/크기 틀림으로 저절로 갱신된다.**

---

## 규칙 3줄

1. **경로와 파일명이 열쇠다.** 아래 표와 한 글자라도 다르면 인식되지 않는다 (`npm run art` 가 오타를 짚어준다)
2. **크기를 정확히 맞춰라.** 표의 크기는 화면에 놓이는 크기와 **1:1 또는 정확히 2배**로 잡아 뒀다.
   1.5배·0.75배 같은 소수배로 늘어나거나 줄어들면 **디더 패턴이 깨져서 지저분해진다.**
   `npm run art` 가 크기가 다른 파일을 잡아서 알려준다
3. **PNG · 알파 채널 사용 가능.** 인물·소품·적은 배경을 투명으로 비워라

## 그림 규격 (03-ASSET-MODULES §4-1)

- 색은 **5개뿐**이다 — `#0f1f17` 먹 · `#3a3c31` 중간 · `#c2c8a5` 뼈 · `#68735e` 먼지 · `#c0392f` 봉랍(붉은색)
- **그라디언트·소프트 셰이딩 금지.** 중간 계조는 **오더드 디더(Bayer 4×4)** 로만 만든다
- 안티앨리어싱된 픽셀이 한 개도 없어야 한다. 외곽선은 뼈색 2px 하드
- **붉은색은 UI 강조에만.** 배경 아트에는 쓰지 않는다

## 캐릭터 CG — 5명 × 3장

`karin` `juno` `sela` `ilan` `mor` 다섯 명이다.

| 파일 | 크기 | 어디에 |
|---|---|---|
| `star/body_<이름>.png` | 752×792 | 상점 좌측 **전신** — 칸을 통째로 채운다 (1:1) |
| `star/<이름>.png` | 384×480 | **초상** — 생방송에서는 1/2 로, 상점에서는 1:1 로 쓰인다 |
| `star/<이름>_appeal.png` | 384×480 | **어필 컷** — 억지 웃음 + 카메라를 본다 |
| `star/silhouette.png` | 1536×480 | 이름 없는 몸 (384×480 프레임 4칸 가로 배열) |

> **어필 컷 한 장이 이 게임의 썸네일이다** (M06 §7). 다섯 명 중 한 명만 그린다면 이것부터 그려라.
>
> 전신을 안 주면 초상이, 초상도 안 주면 실루엣이 대신 나온다. 순서대로 내려간다.

## 버튼 · 패널 CG (9-slice)

**늘어나는 그림이다.** 버튼 하나를 267×96 부터 744×72 까지 온갖 크기로 쓴다.
바깥 모서리는 그대로 두고 가운데만 늘린다. 그래서 작은 그림 한 장이면 충분하다.

| 파일 | 크기 | 모서리 | 어디에 |
|---|---|---|---|
| `ui/button.png` | 32×32 | 8px | 버튼 평상 |
| `ui/button_hover.png` | 32×32 | 8px | 마우스를 올렸을 때 |
| `ui/button_danger.png` | 32×32 | 8px | 되돌릴 수 없는 선택 (소생 · 어필 · 훼손) |
| `ui/button_ghost.png` | 32×32 | 8px | 보조 · 비활성 |
| `ui/panel.png` | 48×48 | 12px | 패널 (융기) |
| `ui/panel_sunken.png` | 48×48 | 12px | 패널 (함몰 — 목록 · 채팅창) |

**모서리 8px** = 네 귀퉁이 8×8 픽셀은 절대 늘어나지 않는다. 장식은 그 안에 넣어라.
가운데 16×16 은 가로세로로 반복해 늘어나므로 **이어져도 티가 안 나는 무늬**여야 한다.

> `ui/button.png` **한 장만** 줘도 된다. 나머지 상태는 그 그림 위에 테두리 색으로만 구분한다.

## 되돌리기

이 폴더에서 파일을 **지우고** `npm run art` 를 다시 돌리면 그 자리만 플레이스홀더로 돌아간다.
전부 되돌리려면 이 폴더를 비우면 된다 (이 README 는 남겨둬라).

플레이스홀더를 새로 만들고 싶으면 `npm run art:placeholder`.
